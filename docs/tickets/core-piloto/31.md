## What to build

Liberação explícita dos arquivos necessários ao destinatário, respeitando revogação e restrição de origem.

Esta é a fatia 31 do core aprovado. Aplicam-se as regras transversais da especificação principal; não há autorização para dados reais ou contratação implícita.

## Acceptance criteria

- [ ] Encaminhador seleciona somente anexos cuja liberação está autorizado a conceder para o destinatário específico.
- [ ] Receber tarefa ou ler instrução não abre todos os arquivos nem os relatos de origem.
- [ ] Arquivo precisa estar aprovado; revalidar escola, concessão e restrição no acesso, inclusive após revogação.
- [ ] Permissão de leitura não implica exportação; mudanças e downloads ficam auditados.
- [ ] Jornada tarefa → anexo e integração real negam arquivo não selecionado, quarentena, outro destinatário e acesso após perda de autorização.
- [ ] Entrega demonstrável/verificável pela fronteira pública: persistência, API, interface aplicável e testes comportamentais, com isolamento, autorização e auditoria desde o recurso entregue.
- [ ] Seguir arquitetura e referências de UI do PRD/spec quando aplicáveis; documentar checks realmente executados e pendências, sem substituir integração real por mocks ou declarar passos não realizados.
